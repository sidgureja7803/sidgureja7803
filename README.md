# 🚀 Local Setup

### Clone the repository

```bash
git clone https://github.com/sidgureja7803/Portfolio.git
```

### Move into the directory

```bash
cd Portfolio
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm start
```

Open:

```text
http://localhost:3000
```

---

# 📦 Production Build

```bash
npm run build
```

The optimized production build will be available in:

```text
build/
```
